# 🎓 Личный бренд преподавателя ВУЗа — ВКонтакте

Одностраничное веб-приложение (**один HTML-файл**, без сервера) для управления личным брендом преподавателя ВКонтакте. Данные сохраняются в XML-файл на вашем компьютере; токены API — только в localStorage браузера.

📖 Подробное научное описание всех функций: [DESCRIPTION.md](DESCRIPTION.md)

## 🚀 Быстрый старт
- **GitHub Pages**: включите Pages для репозитория — приложение доступно по адресу `https://ЛОГИН.github.io/РЕПО/`
- **Локально**: просто откройте `index.html` в Chrome/Edge (рекомендуется: прямая запись в файл через File System Access API)
  ```bash
  npx serve .   # либо любой локальный статический сервер
  ```
1. Нажмите «➕ Новый профиль» или «📂 Открыть файл» → введите ФИО и должность.
2. В ⚙ настройках укажите токены DeepSeek и VK API и ссылку на стену. Опционально — сервисный ключ доступа VK (dev.vk.com) и «Сообщество или ID» для загрузки чужих публичных стен.
3. 💾 Сохраните XML-файл на компьютер.

## 📋 Возможности
- **📅 Модуль 1 «Планировщик»** — генерация контент-плана через DeepSeek по 4 стратегиям: из документа (.docx/.pdf/.txt), по темам, по аналитике стены (поле analyticsRef), по пользовательским промптам (библиотека промптов в XML, загрузка из .txt, снимки промптов).
- **📝 Модуль 2 «Контент-план»** — редактирование дат/тем/форматов/целей, генерация и перегенерация текстов, кнопка «🤖 Промпт», дублирование «📑» + «✍ Переписать», блокировка опубликованных постов «🔒 Publ.», публикация «📤 Опубликовать» (wall.post, отложенная публикация), экспорт JSON/CSV (BOM).
- **📊 Модуль 3 «Аналитика»** — загрузка стены через VK API (JSONP) или парсинг сохранённого HTML (4 стратегии + диагностика), метрики и ER, топ-5, сводные показатели, аудит личного бренда через DeepSeek (сильные/слабые стороны, стратегия, 7 шагов, 5 идей).
- **💾 Хранение** — всё в XML-файле (кроме токенов); автосохранение с debounce; красная кнопка при несохранённых изменениях.

## 🔑 Настройка API
- **DeepSeek**: platform.deepseek.com → API Keys → вставить `sk-...` в ⚙
- **VK (пользовательский токен)**: vkhost.github.io → VK Standalone → галочка «Стена» → скопировать `vk1.a...` в ⚙ — нужен для публикации.
- **VK (сервисный ключ, опционально)**: dev.vk.com → настройки приложения → «Сервисный ключ доступа» → в ⚙ + поле «Сообщество или ID» (например, `inpitsstu` или `-12345678`) — позволяет читать публичные стены/сообщества без пользовательского токена.

## 🛠 Технологии
Tailwind CSS, mammoth.js, pdf.js (все — через CDN в одном файле), File System Access API, DOMParser, JSONP, UUID v4.

## 🐛 Частые проблемы
- Кнопка «Сохранить» скачивает файл вместо перезаписи → используйте Chrome/Edge (File System Access API).
- CORS при загрузке стены → укажите токен VK API (JSONP) или загрузите сохранённый HTML («Веб-страница полностью»).
- DeepSeek не генерирует → проверьте токен `sk-...`, баланс и консоль F12.
- Посты не публикуются → прав `wall`, открытая стена, кнопка активна только для постов на сегодня.
