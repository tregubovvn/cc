📅 Генератор контент-плана

Загрузите плановый документ (.docx, .pdf, .txt) — текст будет извлечён и передан DeepSeek для формирования контент-плана.

Укажите темы и количество постов по каждой теме.

Генерация плана на основе загруженной аналитики стены (модуль «📊 Аналитика»). Сначала загрузите данные стены.

📝 Контент-план

Контент-план пуст. Перейдите в «📅 Планировщик» и сгенерируйте план.

📊 Аналитика страницы

Способ 1: Через VK API (надёжно, полные метрики)

Работает с пользовательским токеном (wall + ссылка на стену) или с сервисным ключом доступа (dev.vk.com) для чтения публичных стен и сообществ — укажите «Сообщество или ID» в ⚙ Настройках.

Способ 2: Парсинг HTML-файла (без токена, обходит CORS)

Откройте стену → Ctrl+S → «Веб-страница полностью» → загрузите файл сюда.

🧠 Аудит личного бренда через DeepSeek

DeepSeek проанализирует топ-20 постов по вовлечённости и сформирует отчёт: сильные стороны, слабые места, стратегия, 7 шагов на месяц, 5 идей постов.

Данные хранятся локально в XML-файле • Токены — только в localStorage • Без телеметрии • MIT
